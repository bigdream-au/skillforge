# 🔥 SkillForge

> **Turn any goal into a bite-sized learning roadmap, powered by AI.** 🚀

SkillForge is an AI-powered micro-learning roadmap generator. Tell it what you want to learn, how much time you have each day, and your current level, and it builds a step-by-step path of short lessons you can finish in minutes, then tracks your progress along the way. 🎯

---

## ✨ Why SkillForge?

Most people don't fail at learning because they lack motivation. They fail because the goal feels too big. SkillForge breaks big goals into small daily wins:

- 🧩 **Micro-lessons**: every step is short and focused
- 🗺️ **Personalized roadmaps**: built around your goal, level, and daily time
- 📈 **Progress tracking**: see exactly how far you've come
- 🔗 **Shareable roadmaps**: make a roadmap public so others can follow it

| 🧪 Testing | Vitest |

---

## 🏗️ Architecture Highlights

- 🔐 **Row Level Security on every table**, so data access is enforced in the database, not only in app code
- 🧱 **Service layer** that keeps database queries out of UI components
- 🛡️ **Zod-validated AI output**, because LLM responses are never trusted to match the schema
- ⏱️ **Rate limiting** on AI generation to protect API quota
- ⚡ **Server Components by default**, with client components only where interactivity is needed

### 🗃️ Data Model

`profiles` → `roadmaps` → `steps` → `step_resources`, plus `progress` (one row per user per step) and `activity_log` for streaks.

## 🚀 Getting Started

### Prerequisites

- Node.js 20 or higher
- A free [Supabase](https://supabase.com/) project
- An API key from your chosen AI provider

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/YOUR-USERNAME/skillforge.git
cd skillforge

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env.local
# then fill in the values

# 4. Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) 🎉

### 🔑 Environment Variables

```bash
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=   # server only, never expose to the browser
GEMINI_API_KEY=              # or the key for your chosen AI provider
```

> ⚠️ Never commit `.env.local` or share your service role key.
